Criador de Flashcards — Criar, Estudar & Imprimir Flashcards Grátis

Em resumo: escrever uma frente e um verso para adicionar um cartão, construir um baralho inteiro, depois estudá-lo com cartões que viram, mistura e acompanhamento sei / não sei. Os baralhos guardam-se automaticamente no navegador, e podem exportar-se ou importar-se como CSV ou JSON, ou imprimi-los em papel.

Os flashcards funcionam porque obrigam a recordar: vê-se a pergunta, luta-se pela resposta e depois verifica-se. É essa luta que constrói a memória. Criar abaixo um baralho para qualquer disciplina — vocabulário, datas, fórmulas, definições — e estudá-lo em rondas curtas, mantendo em rotação apenas os cartões que falham.

🔒 Privado desde a conceção: os baralhos são guardados apenas neste navegador, neste dispositivo. Nada é carregado para um servidor.

Modo de Estudo

Adicionar pelo menos um cartão acima e depois começar a estudar aqui.

Revisão Espaçada (SM-2) - Modo de Memória de Longo Prazo

O modo de estudo acima é para empinar. Este modo agenda revisões como o Anki: classificar cada cartão Outra vez / Difícil / Bom / Fácil e o cartão volta depois de 1 dia, 6 dias, depois intervalos cada vez maiores. Os cartões só são mostrados quando estão devidos, pelo que uma visita diária demora minutos. O progresso é guardado por baralho neste navegador.

Como Usar o Criador de Flashcards

  1. Dar um nome ao baralho — por exemplo "Biology Chapter 4" — para o poder encontrar outra vez mais tarde.
  2. Adicionar cartões: escrever a pergunta ou o termo em Frente e a resposta em Verso, depois premir Adicionar cartão. Repetir; os cartões aparecem na lista onde podem ser editados ou apagados.
  3. Estudar: no Modo de Estudo, ler a frente, dizer a resposta na cabeça, depois clicar no cartão (ou Virar) para verificar. Ser honesto — essa honestidade é o que torna o acompanhamento útil.
  4. Ordenar-se a si próprio: premir "Já sei" ou "Ainda a aprender" para cada cartão. Quando a ronda terminar, recomeçar só com os cartões falhados até não restar nenhum.
  5. Guardar & partilhar: os baralhos guardam-se automaticamente neste navegador. Usar Exportar CSV/JSON para fazer cópia de segurança de um baralho ou enviá-lo a um colega, e Importar para o carregar de volta.

Como Funciona

O criador guarda cada baralho como uma lista simples de pares frente/verso no armazenamento local do navegador — o mesmo formato simples usado pelas exportações em CSV e JSON, pelo que os dados nunca ficam presos. O modo de estudo mostra um cartão de cada vez e mantém duas pilhas: conhecidos e ainda a aprender. Misturar usa uma reordenação aleatória do baralho para não se poder memorizar a sequência em vez das respostas. A vista de impressão dispõe cada cartão numa grelha com frentes e versos numerados, para uma página impressa se tornar um conjunto de cartões de papel em segundos.

Perguntas Frequentes

Como faço um bom flashcard?

Manter uma ideia por cartão: uma pergunta curta, um termo ou um enunciado na frente e uma resposta curta e exata no verso. "What is the capital of France?" funciona melhor do que um parágrafo. Se uma resposta tiver três partes, fazer três cartões.

Onde estão guardados os meus baralhos?

No armazenamento local do seu navegador, apenas neste dispositivo. Nada é carregado. Se limpar os dados do site do navegador, os baralhos guardados são apagados — por isso, exportar os baralhos importantes como ficheiros CSV ou JSON como cópia de segurança.

Em que formato são as exportações CSV e JSON?

As exportações em CSV têm um front,back linha de cabeçalho e aspas padrão, para abrirem no Excel, no Google Sheets, em importadores ao estilo do Anki e na maioria das aplicações de flashcards. As exportações JSON contêm o nome do baralho e um array de cartões com campos front/back. Pode importar-se qualquer um dos formatos de volta para esta ferramenta.

Como ajuda o acompanhamento sei / não sei?

Quando se marca um cartão como "Ainda a aprender", ele fica na pilha de revisão; os cartões "Já sei" são postos de lado. No fim de uma ronda, pode recomeçar só com os cartões falhados — isto é prática de recuperação focada exatamente onde é precisa, a forma mais rápida de fechar lacunas antes de um exame.

O que é o modo de Revisão Espaçada (SM-2)?

Agenda os cartões como o Anki faz. Classificar cada cartão revisto como Outra Vez, Difícil, Bom ou Fácil; o algoritmo SM-2 trá-lo de volta após intervalos crescentes - 1 dia, 6 dias, depois mais longos - para cada cartão ser revisto mesmo antes de ser esquecido. Os cartões devidos são escolhidos automaticamente todos os dias, e o progresso é guardado por baralho no navegador.

Posso imprimir flashcards para usar em papel?

Sim — usar o botão Imprimir Cartões. Os cartões são dispostos numa grelha de duas colunas com frentes e versos listados por ordem, prontos para recortar. Para cartões de papel de dupla face, escrever os números correspondentes no verso.
