Balanceador de Equações Químicas — Balanceado, e Comprovadamente Balanceado

Em resumo: escrever uma equação não balanceada com uma seta ( -> ) e obter os menores coeficientes inteiros que a balanceiam — seguido de uma verificação de átomos a mostrar a contagem de cada elemento dos dois lados, para se poder ver que o equilíbrio é verdadeiro.

Balancear por tentativa e erro funciona até chegarem as equações de combustão e de oxidação-redução. Este balanceador resolve o sistema subjacente com exatidão — a mesma álgebra linear que o software de um químico usa — e depois prova a sua resposta voltando a contar cada átomo.

🔒 Privado desde a conceção: as equações são resolvidas neste dispositivo; nada é guardado nem carregado.

Como Usar

  1. Escrever a equação: substâncias separadas por +, lados por ->. Usar símbolos de elementos adequados e parênteses conforme necessário: p. ex. Fe + O2 -> Fe2O3, Ca(OH)2 + HCl -> CaCl2 + H2O.
  2. Omitir quaisquer coeficientes que tenham sido escritos — ou incluí-los; os números existentes são ignorados e recalculados.
  3. Ler a equação balanceada e a verificação de átomos por baixo dela: cada elemento tem de mostrar o mesmo número dos dois lados — essa igualdade é a definição de balanceado.

Como Funciona

Cada substância é analisada em contagens de átomos (o mesmo analisador da Calculadora de Massa Molar). O balanceamento é um sistema de uma equação por elemento; é resolvido com exatidão com aritmética de frações (eliminação gaussiana — sem decimais, sem arredondamentos) e a variável livre é escalada para os menores números inteiros positivos. Se uma entrada não tiver solução, ou combinar secretamente duas reações independentes, a ferramenta diz isso em vez de inventar coeficientes. Uma recontagem final independente dos átomos dos dois lados verifica cada resultado antes de ser apresentado.

Perguntas Frequentes

Porque os menores números inteiros?

Convenção: 2H2 + O2 → 2H2O, e não 4H2 + 2O2 → 4H2O, embora ambos balanceiem. A ferramenta reduz os coeficientes pelo seu maior divisor comum, correspondendo ao estilo dos manuais.

Consegue balancear equações iónicas ou meias-equações?

Balanceia equações moleculares completas. A carga não é acompanhada, pelo que as semiequações iónicas com eletrões (e−) estão fora do seu âmbito — balanceá-las pelo método das semiequações que se está a aprender, e usar esta ferramenta para a verificação da equação completa.

Diz "mais do que uma solução independente". O que significa?

A equação pode ser balanceada de maneiras genuinamente diferentes — normalmente porque cola duas reações separadas (um caso clássico é o carbono a arder para CO e CO2 ao mesmo tempo). Dividi-la nas duas reações verdadeiras e balancear cada uma.
