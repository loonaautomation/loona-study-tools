Gerador de Palavras Cruzadas — Puzzles com Interseções a Sério

Em resumo: introduzir palavras com as suas pistas, e o gerador constrói umas palavras cruzadas genuínas: as palavras cruzam-se em letras partilhadas, as pistas são numeradas nas horizontais e verticais, e pode imprimir-se o puzzle mais uma chave de respostas separada.

As palavras cruzadas são o treino de vocabulário mais profundo deste site — as letras que se cruzam dão aos participantes informação parcial, pelo que uma palavra difícil pode ser desbloqueada por uma fácil. Até agora, fazer uma à mão levava uma noite de papel quadriculado.

Palavras Cruzadas — Chave de Respostas

Como Usar

  1. Escrever palavras e pistas, um por linha como PALAVRA = pista. Palavras de 3–12 letras que partilham letras comuns (muitas vogais e S, T, R, N) cruzam-se com mais facilidade.
  2. Gerar: a palavra mais comprida é colocada primeiro, depois cada palavra é encaixada através de uma palavra colocada numa letra correspondente.
  3. Se uma palavra não couber, está identificado na linha de estado. Gerar de novo para experimentar outra disposição, ajustar a lista de palavras ou aceitar um puzzle sem ele.
  4. Imprimir o puzzle para a turma e a chave de respostas separadamente para si.

Como Funciona

O gerador trabalha numa grelha interna grande. A palavra mais comprida atravessa o meio; cada palavra posterior tem de cruzar uma palavra existente numa letra idêntica, na direção perpendicular, sem tocar em vizinhos paralelos nem ultrapassar o fim de outra palavra — as mesmas regras que um criador humano segue. As colocações que cruzam mais letras são preferidas. As palavras que não podem cruzar legalmente nada são relatadas em vez de serem largadas silenciosamente, e a grelha terminada é aparada e numerada a partir das células iniciais das palavras colocadas.

Perguntas Frequentes

Porque é que uma das minhas palavras não coube?

Uma palavra só pode ser colocada onde cruza uma palavra existente numa letra partilhada, com espaço livre à volta. Palavras com letras raras (Q, X, Z, J) ou sem vogais muitas vezes não conseguem cruzar. Adicionar uma palavra de ponte que partilhe letras com ambas, ou gerar de novo — os empates são decididos ao acaso.

Quantas palavras fazem umas boas palavras cruzadas?

Oito a quinze palavras de comprimentos mistos. Cabem mais palavras quando partilham letras comuns; listas temáticas (todos animais, toda geografia) partilham naturalmente letras de vocabulário.

Os alunos podem resolvê-lo no ecrã?

Esta versão é primeiro para imprimir: o puzzle e a chave são concebidos para papel. Os alunos resolvem com um lápis, que a maioria dos professores prefere para palavras cruzadas de qualquer maneira.

As pistas que escrevo são mostradas exatamente?

Sim — o texto da pista aparece inalterado, numerado pela posição na grelha de cada palavra, dividido em listas Horizontais e Verticais.
