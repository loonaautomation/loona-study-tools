연결 학습지 생성기 — 용어를 정의와 맞추기

요컨대: 다음과 같이 쌍을 입력하세요 용어 = 정의, 한 줄에 하나씩 입력하면 인쇄용 학습지가 만들어져요: 왼쪽에는 번호가 매겨진 용어, 오른쪽에는 섞여서 문자로 표시된 정의, 그리고 교사용 별도 정답지가 있어요.

짝 맞추기 문제는 정확한 이해를 테스트하기 때문에 교실의 필수품이에요 — 용어를 절반만 아는 학생은 숨을 수 없어요. 손으로 만드는 것은 정의를 섞고 실수 없이 정답지를 쓰는 것을 뜻해요; 이 도구는 입력한 하나의 목록에서 몇 초 만에 둘 다 해요.

🔒 설계부터 비공개: 쌍은 이 기기에서만 처리돼요. 절대 업로드되지 않아요.
이름: ______________날짜: ______________

왼쪽의 각 용어를 오른쪽의 올바른 정의와 맞추세요. 상자에 글자를 쓰세요.

정답지

사용 방법

  1. 학습지에 제목 붙이기 그리고 쌍을 입력하세요, 한 줄에 하나씩, 다음과 같이 용어 = 정의.
  2. 생성: 왼쪽 열은 답 상자와 함께 순서를 유지해요; 오른쪽 열은 A, B, C… 글자와 함께 섞여요.
  3. 학습지 인쇄 학생을 위해요 — 각 상자에 올바른 글자를 써요.
  4. 정답지 따로 인쇄 — 같은 섞기에서 생성되므로, 항상 일치해요.

작동 방식

생성기는 각 줄을 첫 = 기호에서 분석한 뒤, Fisher–Yates 섞기로 정의를 섞어요. 한 가지 보호 장치가 있어요: 섞기가 모든 정의를 원래 위치에 두게 되면 (학습지가 무의미해져요), 첫 두 개를 맞바꿔요. 정답지는 섞인 열에서 각 용어의 정의를 찾아 계산되므로, 학습지와 정답지가 어긋날 수 없어요.

자주 묻는 질문

제 플래시카드 덱을 여기서 다시 쓸 수 있어요?

예 — 형식은 같은 아이디어예요: 앞면 = 용어, 뒷면 = 정의. 스프레드시트에서 쌍을 복사하거나 새로 입력하세요; 플래시카드를 플래시카드 만들기에 보관하면, 같은 쌍이 두 도구 모두에서 작동해요.

몇 쌍이 가장 좋아요?

학습지당 다섯 쌍에서 열다섯 쌍까지. 더 적으면 하찮게 느껴지고; 스무 쌍쯤 넘으면 학생이 생각하는 것보다 페이지를 찾는 데 더 오래 걸려요.

왜 줄이 건너뛰어졌어요?

= 기호가 없는 줄은 용어와 정의로 나눌 수 없어 건너뛰고 보고돼요. =를 추가하고 다시 생성하세요.

정의가 반복되거나 비슷할 수 있어요?

할 수 있어요. 하지만 짝짓기 학습지는 각 정의가 하나의 용어에만 분명히 맞을 때 가장 잘 작동해요 — 거의 동일한 정의는 문제를 어렵게가 아니라 모호하게 만들어요.
