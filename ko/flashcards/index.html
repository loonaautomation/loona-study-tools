플래시카드 만들기 — 플래시카드 만들기, 공부 & 인쇄 무료

요컨대: 앞면과 뒷면을 입력해서 카드를 추가하고, 전체 덱을 만든 뒤, 뒤집기 카드, 섞기와 아는/모르는 추적으로 학습하세요. 덱은 브라우저에 자동 저장되고, CSV나 JSON으로 내보내거나 가져올 수 있고, 종이에 인쇄할 수도 있어요.

플래시카드는 회상을 강제하기 때문에 효과가 있어요: 문제를 보고, 답하려고 애쓴 뒤, 스스로 확인해요. 그 애씀 자체가 기억을 만들어요. 아래에서 어떤 과목으로든 덱을 만드세요 — 어휘, 날짜, 공식, 정의 — 그리고 짧은 라운드로 공부하면서 틀린 카드만 회전 속에 남기세요.

🔒 설계부터 비공개: 덱은 이 기기의 이 브라우저에만 저장돼요. 서버에 업로드되는 것은 없어요.

공부 모드

위에 카드를 최소 하나 추가한 뒤, 여기서 공부를 시작하세요.

간격 복습 (SM-2) - 장기 기억 모드

위쪽의 공부 모드는 벼락치기용이에요. 이 모드는 Anki처럼 복습을 예약해요: 각 카드를 평가하세요 다시 / 어려움 / 좋음 / 쉬움 그리고 카드는 1일 뒤, 6일 뒤, 그다음 점점 더 긴 간격으로 돌아와요. 카드는 다음일 때만 표시돼요 예정, 그래서 매일 방문해도 몇 분이면 돼요. 진행 상황은 이 브라우저에 덱별로 저장돼요.

플래시카드 만들기 사용 방법

  1. 덱 이름 정하기 — 예를 들어 "생물 4장" — 나중에 다시 찾을 수 있게요.
  2. 카드 추가: 앞면에 질문이나 용어를, 뒷면에 답을 입력한 뒤, 카드 추가를 누르세요. 반복하세요; 카드는 편집하거나 삭제할 수 있는 목록에 나타나요.
  3. 공부: 학습 모드에서는, 앞면을 읽고, 마음속으로 답을 말한 뒤, 카드를 클릭 (또는 뒤집기)해서 확인하세요. 솔직하세요 — 그 솔직함이 추적을 유용하게 만들어요.
  4. 스스로 분류: 모든 카드에 "알아요" 또는 "아직 배우는 중"을 누르세요. 라운드가 끝나면, 놓친 카드만으로 아무것도 남지 않을 때까지 다시 시작하세요.
  5. 저장 & 공유: 덱은 이 브라우저에 자동 저장돼요. CSV/JSON 내보내기를 써서 덱을 백업하거나 반 친구에게 보내고, 가져오기로 다시 불러오세요.

작동 방식

만들기는 각 덱을 브라우저의 로컬 저장소에 앞/뒤 쌍의 간단한 목록으로 저장해요 — CSV와 JSON 내보내기가 쓰는 같은 단순한 형식이라, 데이터가 갇히지 않아요. 학습 모드는 한 번에 카드 하나를 보여 주고 두 개의 더미를 유지해요: 아는 것과 아직 배우는 중. 섞기는 덱의 무작위 재배열을 써서 답 대신 순서를 외울 수 없게 해요. 인쇄 보기는 모든 카드를 번호가 매겨진 앞면과 뒷면과 함께 격자로 배치해서, 인쇄된 페이지가 몇 초 만에 종이 카드 세트가 돼요.

자주 묻는 질문

좋은 플래시카드는 어떻게 만들어요?

카드당 하나의 생각을 유지하세요: 앞면에 짧은 질문, 용어 또는 프롬프트, 뒷면에 짧고 정확한 답. "What is the capital of France?"가 한 단락보다 나아요. 답에 세 부분이 있으면, 카드 세 장을 만드세요.

제 덱은 어디에 저장돼요?

여러분의 브라우저 로컬 저장소에, 이 기기에만 있어요. 업로드되는 것은 없어요. 브라우저의 사이트 데이터를 지우면 저장된 덱이 삭제돼요 — 그러니 중요한 덱은 백업으로 CSV나 JSON 파일로 내보내세요.

CSV와 JSON 내보내기는 어떤 형식이에요?

CSV 내보내기에는 다음이 있어요 front,back 헤더 행과 표준 인용이 있어서, Excel, Google Sheets, Anki 스타일 가져오기와 대부분의 플래시카드 앱에서 열려요. JSON 내보내기는 덱 이름과 앞/뒤 필드가 있는 카드 배열을 포함해요. 어느 형식이든 이 도구로 다시 가져올 수 있어요.

알기 / 모르기 추적이 어떻게 도움이 돼요?

카드를 "아직 배우는 중"으로 표시하면 복습 더미에 남아요; "알아요" 카드는 따로 두어요. 라운드가 끝나면 놓친 카드만으로 다시 시작할 수 있어요 — 이것은 필요한 바로 그곳에 집중된 인출 연습으로, 시험 전에 격차를 메우는 가장 빠른 방법이에요.

간격 복습 (SM-2) 모드란 무엇이에요?

Anki가 하는 방식으로 카드를 예약해요. 복습한 카드를 다시, 어려움, 좋음 또는 쉬움으로 평가하세요; 그러면 SM-2 알고리즘이 커지는 간격 — 1일, 6일, 그다음 더 길게 — 뒤에 다시 가져와서, 잊기 직전에 각 카드를 복습하게 해요. 기한이 된 카드는 매일 자동으로 뽑히고, 진행 상황은 브라우저에 덱별로 저장돼요.

종이로 쓸 플래시카드를 인쇄할 수 있어요?

예 — 카드 인쇄 버튼을 쓰세요. 카드는 두 열 격자로 배치되고 앞면과 뒷면이 순서대로 나열되어, 잘라 낼 준비가 돼요. 양면 종이 카드는 뒷면에 대응하는 번호를 쓰세요.
