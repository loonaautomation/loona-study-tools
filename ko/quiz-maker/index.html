퀴즈 만들기 — 즉시 채점 & 인쇄 가능한 정답지로 퀴즈 만들기

요컨대: 객관식, 참/거짓과 단답형 문제로 퀴즈를 만든 뒤, 학생이 즉시 채점과 전체 답 복습으로 화면에서 도전하게 하세요 — 또는 종이 시험을 위해 퀴즈와 별도의 정답지를 인쇄하세요. 퀴즈를 JSON으로 내보내고 가져오세요.

학급 한 세트의 퀴즈를 손으로 채점하면 저녁이 다 가요. 아래에서 퀴즈를 한 번 만드세요: 학생은 어떤 폰이나 컴퓨터에서든 도전해서 점수와 복습을 즉시 받거나, 교실용으로 인쇄하고 정답지는 혼자 보관할 수 있어요.

🔒 설계부터 비공개: 퀴즈는 이 기기의 이 브라우저에서만 만들어지고 저장돼요. 업로드되는 것은 없어요.

문제 추가

퀴즈에 도전하세요

퀴즈 만들기 사용 방법

  1. 퀴즈에 제목 붙이기 그리고 문제 유형을 선택하세요: 객관식, 참/거짓 또는 단답형.
  2. 질문을 쓰세요. 객관식에서는 네 가지 선택지를 모두 채우고 어느 것이 올바른지 골라 선택하세요. 단답형에서는 | 로 구분한 대안을 추가할 수 있어요.
  3. 모든 문제 추가 — 목록에 나타나고, 그중 어느 것이든 삭제할 수 있어요.
  4. 실행: 학생은 도전 섹션에서 답하고 제출을 눌러 점수와 문제별 복습을 봐요.
  5. 또는 종이로: 퀴즈 인쇄는 깔끔한 문제지 (이름과 날짜 줄 포함)를 나눠 줘요; 정답지 인쇄는 채점용으로 정답지를 따로 인쇄해요.
  6. 유지: JSON 내보내기는 전체 퀴즈를 다음 학기에 다시 가져오거나 동료와 공유할 수 있는 파일로 저장해요.

작동 방식

퀴즈는 브라우저에 구조화된 데이터로 저장돼요: 제목과 문제 목록. 각각 유형, 텍스트와 정답이 있어요. 도전 모드는 문제를 양식으로 렌더링해요; 제출하면, 작은 채점 엔진이 각 답을 비교해요 — 객관식과 참/거짓은 정확히, 단답형은 대문자와 간격을 정규화한 뒤에요 — 그런 뒤 복습을 만들어요. 각 문제를 맞았는지 틀렸는지 표시하고 정답을 보여 줘요. 인쇄 보기는 같은 데이터에서 생성돼요: 퀴즈 시트는 의도적으로 답을 생략하고, 정답지는 순서대로 나열해요.

자주 묻는 질문

어떤 문제 유형을 쓸 수 있어요?

세 가지: 네 가지 선택지가 있는 객관식 (올바른 것을 표시해요), 참/거짓, 그리고 단답형. 단답형은 확인이 대문자와 여분의 공백에 관대하고, | 문자로 구분해서 허용 가능한 답을 여러 개 허용할 수 있어요 — 예를 들어 USA | 미국 | 아메리카.

퀴즈는 어떻게 채점돼요?

각 문제는 한 점의 가치가 있어요. 객관식과 참/거짓은 정확히 확인하고; 단답형은 대소문자와 간격을 정리한 뒤 비교해요. 제출 후 학생은 점수와 모든 문제의 정답을 보여 주는 전체 복습을 봐요.

종이 시험용으로 퀴즈를 인쇄할 수 있어요?

예 — 인쇄 버튼 두 개가 제공돼요. "퀴즈 인쇄"는 이름, 날짜와 쓴 답을 위한 공간과 함께 문제를 인쇄하고, 답은 표시되지 않아요. "정답지 인쇄"는 선생님을 위한 별도의 정답지를 인쇄해요. 정답지가 학생에게 닿지 않도록 따로 인쇄하세요.

제 퀴즈는 어디에 저장되고, 재사용할 수 있어요?

만들고 있는 퀴즈는 이 기기의 브라우저에 자동으로 저장돼요. JSON 내보내기를 써서 영구 사본을 파일로 저장하고, 다른 선생님과 공유하거나, JSON 가져오기로 다른 기기에 불러오세요.

학생들이 시도 모드에서 답을 보고 부정행위를 할 수 있어요?

답은 학생이 제출한 뒤, 검토 화면에서만 공개돼요. 모든 기기 내 도구와 마찬가지로, 마음먹은 학생은 페이지 코드를 들여다볼 수 있어요 — 중요한 시험에서는 대신 인쇄한 퀴즈를 사용하세요.
