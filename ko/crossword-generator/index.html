십자말풀이 생성기 — 실제로 교차하는 퍼즐

요컨대: 단서와 함께 단어를 입력하면, 생성기는 진정한 십자말풀이를 만들어요: 단어가 공유된 글자에서 서로 교차하고, 단서는 가로와 세로로 번호가 매겨지며, 퍼즐과 별도의 정답지를 인쇄할 수 있어요.

크로스워드는 이 사이트에서 가장 깊이 있는 어휘 운동이에요 — 교차하는 글자가 푸는 사람에게 부분 정보를 주거든요. 그래서 어려운 단어를 쉬운 단어로 풀 수 있어요. 지금까지는 손으로 만드는 데 모눈종이와 함께 한 저녁이 걸렸어요.

사용 방법

  1. 단어와 단서를 입력하세요, 한 줄에 하나씩 다음과 같이 단어 = 단서. 공통 문자가 많은 3–12자 단어 (모음과 S, T, R, N이 많은 단어)가 가장 잘 교차해요.
  2. 생성: 가장 긴 단어가 먼저 배치되고, 그런 뒤 각 단어는 일치하는 글자에서 배치된 단어를 가로질러 맞춰져요.
  3. 단어가 들어가지 않으면, 상태 줄에 이름이 표시돼요. 다시 생성해서 다른 배치를 시도하거나, 단어 목록을 조정하거나, 그 단어 없이 퍼즐을 확정하세요.
  4. 퍼즐 인쇄 학급을 위해, 그리고 정답지는 자신을 위해 따로요.

작동 방식

생성기는 큰 내부 격자에서 작동해요. 가장 긴 단어가 가운데를 가로질러요; 이후의 모든 단어는 동일한 글자에서 기존 단어와 교차해야 하고, 수직 방향으로, 평행한 이웃에 닿지 않고 다른 단어의 끝을 넘어가지 않으면서요 — 사람이 만드는 사람과 같은 규칙이에요. 가장 많은 글자와 교차하는 배치가 선호돼요. 합법적으로 아무것과도 교차할 수 없는 단어는 조용히 버려지는 대신 보고되고, 완성된 격자는 배치된 단어의 시작 칸에서 다듬어지고 번호가 매겨져요.

자주 묻는 질문

왜 제 단어 하나가 들어가지 않았어요?

단어는 공통 문자에서 기존 단어와 교차하는 곳에만, 주위에 빈 공간을 두고 배치할 수 있어요. 희귀한 문자 (Q, X, Z, J)가 있거나 모음이 없는 단어는 교차하지 못하는 경우가 많아요. 양쪽과 문자를 공유하는 연결 단어를 추가하거나 다시 생성하세요 — 동점인 경우는 무작위로 정해져요.

단어 몇 개가 좋은 크로스워드를 만들어요?

길이가 섞인 여덟 개에서 열다섯 개까지의 단어. 공통 글자를 공유하면 더 많은 단어가 들어가요; 주제 목록 (모두 동물, 모두 지리)은 자연스럽게 어휘 글자를 공유해요.

학생들이 화면에서 풀 수 있어요?

이 버전은 인쇄 우선이에요: 퍼즐과 정답지는 종이용으로 설계되었어요. 학생은 연필로 풀어요. 대부분의 선생님이 어차피 십자말풀이에 그것을 선호해요.

제가 쓴 단서가 그대로 표시돼요?

예 — 단서 텍스트는 변경 없이 나타나고, 각 단어의 격자 위치로 번호가 매겨지며, 가로와 세로 목록으로 나뉘어요.
