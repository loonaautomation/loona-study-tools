Quiz Maker — Build Quizzes with Instant Scoring & Printable Answer Keys

In short: build a quiz with multiple-choice, true/false and short-answer questions, then let students attempt it on screen with instant scoring and a full answer review — or print the quiz and a separate answer key for a paper test. Export and import quizzes as JSON.

Marking a class set of quizzes by hand eats an evening. Build the quiz once below: students can attempt it on any phone or computer and get their score and a review instantly, or you can print it for the classroom and keep the answer key to yourself.

🔒 Private by design: your quiz is built and saved only in this browser on this device. Nothing is uploaded.

How to Use the Quiz Maker

  1. Title your quiz and choose a question type: multiple choice, true/false or short answer.
  2. Write the question. For multiple choice, fill in all four options and select which one is correct. For short answers, you may add alternatives separated by | .
  3. Add every question — they appear in the list, where you can delete any of them.
  4. Run it: students answer in the Attempt section and press Submit to see their score and a question-by-question review.
  5. Or go paper: Print quiz hands out a clean question paper (with name and date lines); Print answer key prints the key separately for marking.
  6. Keep it: Export JSON saves the whole quiz as a file you can re-import next term or share with a colleague.

How It Works

Your quiz is stored as structured data in your browser: a title plus a list of questions, each with its type, text and correct answer. Attempt mode renders the questions as a form; on submit, a small scoring engine compares each answer — exactly for multiple choice and true/false, and after normalising capitals and spacing for short answers — then builds the review, marking each question right or wrong and showing the correct answer. The print views are generated from the same data: the quiz sheet deliberately omits answers, while the key lists them in order.

Frequently Asked Questions

What question types can I use?

Three: multiple choice with four options (you mark the correct one), true/false, and short answer. For short answers the checking is forgiving about capital letters and extra spaces, and you can allow several acceptable answers by separating them with a | character — for example USA | United States | America.

How is the quiz scored?

Each question is worth one point. Multiple choice and true/false are checked exactly; short answers are compared after tidying capitals and spacing. After submitting, students see their score and a full review showing the correct answer for every question.

Can I print the quiz for a paper test?

Yes — two print buttons are provided. "Print quiz" prints the questions with space for a name, date and written answers, with no answers shown. "Print answer key" prints a separate key for the teacher. Print them separately so the key never reaches students.

Where is my quiz saved, and can I reuse it?

The quiz you are building is saved automatically in your browser on this device. Use Export JSON to save a permanent copy as a file, share it with another teacher, or load it on a different device with Import JSON.

Can students cheat by viewing the answers in attempt mode?

Answers are only revealed after a student submits, in the review. As with any on-device tool, a determined student could inspect the page code — so for high-stakes exams, use the printed quiz instead.
