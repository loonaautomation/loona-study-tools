Random Name Picker — Fair Picks for the Whole Class

In short: paste your class list, press the button, and a name is picked at random with a slot-machine reveal. No-repeat mode guarantees every student is picked once before anyone is picked twice — the fair way to choose who answers, presents or leads.

Picking students by hand is never as fair as it feels — teachers unconsciously favor the front row and the eager hands. A random picker removes the bias, keeps every student quietly alert (anyone could be next), and ends the "you never pick me!" argument for good.

🔒 Private by design: the class list never leaves this page — it is not stored, saved or uploaded anywhere.
—

How to Use It

  1. Paste the class list, one name per line. The counter shows how many students were found.
  2. Leave no-repeat mode on for fairness (recommended): the class is shuffled into a secret order and worked through once before reshuffling.
  3. Press Pick a name — the display spins and lands on a student. Picked names are listed underneath so you can track turns.
  4. Reset turns any time to start a fresh round. Editing the list also resets the round.

How It Works

In no-repeat mode the tool shuffles the whole class once using a Fisher–Yates shuffle (every order equally likely), then works through that order; when the round starts again, the shuffle is repeated with a guard so the last student of the old round is not first again. With no-repeat off, each pick is an independent random choice. The list lives only in the page — paste it fresh each lesson, or keep it in a document you control.

Frequently Asked Questions

Is the picker really fair?

Yes. Fisher–Yates produces every possible order with equal probability, and no-repeat mode simply deals that order out. Over a full round, every student is picked exactly once — fairer than any human habit.

Why does no-repeat matter?

With pure random picks, one student can be chosen three times while another is never chosen — it is normal randomness, but it feels unfair in a classroom. No-repeat mode keeps the surprise while guaranteeing equal turns.

Are the names saved anywhere?

No. The list exists only in this page on your device and disappears when you close it. That is deliberate — student lists should not be uploaded to websites.

Can I use it for groups or prizes?

Certainly — it picks fairly from any list: group leaders, presentation order, reading buddies, or a prize draw at a school event.
