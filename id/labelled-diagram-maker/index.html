Labelled Diagram Pembuat — Pin, Cetak, Kuis

Di pendek: upload apa pun diagram — plant sel, map, machine, skeleton — klik untuk drop numbered pins, dan jenis label untuk setiap. Cetak itu labelled untuk teaching, kosong untuk testing, atau switch di kuis mode dan let siswa jenis labels di layar.

Diagrams adalah where mata pelajaran become visual, tetapi textbooks tidak pernah have tepat diagram Anda perlu di level Anda perlu. Dengan Anda sendiri image ( photo, scan, screenshot) dan pins, apa pun gambar becomes labelled teaching diagram dan self-marking kuis.

🔒 Privat oleh design: Anda image adalah baca locally oleh Anda browser dan adalah tidak pernah uploaded atau stored.

2. Klik anywhere di image untuk tambahkan numbered pin, lalu jenis nya label. Di kuis mode labels sembunyikan dan siswa jenis mereka dari memory.

Bagaimana untuk Gunakan Itu

  1. Pilih image dari Anda perangkat. Itu adalah loaded locally di browser Anda — tidak pernah uploaded anywhere.
  2. Klik image where label belongs; numbered pin appears dan Anda jenis nya label. Klik pin untuk hapus itu.
  3. Cetak dengan labels listed untuk teaching handout, atau ubah kuis mode Di untuk sembunyikan labels pertama untuk tes versi.
  4. Kuis mode: siswa jenis setiap pin's label dan tekan Periksa untuk instan skor dengan corrections.

Cara Kerjanya

Pins adalah stored sebagai percentage positions di image, sehingga mereka stay di benar place di apa pun layar atau cetak ukuran. image itself adalah baca sebagai local data URL oleh Anda browser dan exists hanya di ini page's memory. Kuis jawaban adalah compared ignoring capitals dan extra spaces.

Pertanyaan yang Sering Diajukan

Apa images kerja terbaik?

Hapus diagrams dengan distinct bagian: sains diagrams, maps, anatomy, bagian dari plant atau flower, bicycle, komputer. Busy photographs buat pin placement harder untuk judge.

Adalah my image uploaded atau saved?

Tidak ada. file adalah baca oleh Anda browser ke dalam halaman dan disappears ketika Anda tutup itu. Di sana adalah tidak ada server salin dan nothing di local storage.

Can I cetak kosong versi untuk kertas tes?

Yes — ubah kuis mode Di sebelum mencetak: label daftar hides dan hanya numbered pins cetak, sehingga siswa tulis labels oleh hand.
