Kartu Flash Pembuat — Buat, Belajar & Cetak Kartu Flash Gratis

Di pendek: jenis front dan kembali untuk tambahkan kartu, buat seluruh set kartu, lalu belajar itu dengan balik kartu, acak dan tahu / don't-know melacak. Set kartu simpan secara otomatis di browser Anda, dan Anda can export atau import mereka sebagai CSV atau JSON, atau cetak mereka di kertas.

Kartu Flash kerja because mereka force recall: Anda lihat pertanyaan, struggle untuk jawaban, lalu periksa diri Anda. Itu struggle adalah apa builds memory. Buat set kartu di bawah untuk apa pun mata pelajaran — vocabulary, dates, formulas, definitions — dan belajar itu di pendek ronde, keeping hanya kartu Anda miss di rotation.

🔒 Privat oleh design: Anda set kartu adalah stored hanya di ini browser di ini perangkat. Nothing adalah uploaded untuk server.

Belajar Mode

Tambahkan di least satu kartu di atas, lalu mulai studying di sini.

Spaced Ulasan (SM-2) - Long-Term Memory Mode

Belajar mode di atas adalah untuk cramming. Ini mode schedules reviews seperti Anki: rate setiap kartu Lagi / Sulit / Baik / Mudah dan kartu comes kembali setelah 1 hari, 6 hari, lalu ever-longer selisih. Kartu adalah hanya ditampilkan ketika mereka adalah jatuh tempo, sehingga harian visit membutuhkan menit. Progress adalah saved per set kartu di ini browser.

Bagaimana untuk Gunakan Kartu Flash Pembuat

  1. Nama Anda set kartu — untuk contoh "Biology Chapter 4" — sehingga Anda can temukan itu lagi later.
  2. Tambahkan kartu: jenis pertanyaan atau suku di Front dan jawaban di Kembali, lalu tekan Tambahkan kartu. Repeat; kartu appear di daftar where Anda can ubah atau hapus mereka.
  3. Belajar: di Belajar Mode, baca front, say jawaban di Anda head, lalu klik kartu (atau Balik) untuk periksa. Menjadi jujur — itu honesty adalah apa membuat melacak berguna.
  4. Kelompokkan diri Anda: tekan "Tahu itu" atau "Masih belajar" untuk setiap kartu. Ketika ronde berakhir, restart dengan hanya missed kartu hingga none adalah dibiarkan.
  5. Simpan & bagikan: set kartu simpan secara otomatis di ini browser. Gunakan Export CSV/JSON untuk kembali set kartu up atau send itu untuk classmate, dan Import untuk load satu kembali.

Cara Kerjanya

maker stores setiap set kartu sebagai sederhana daftar dari front/kembali pasangan di browser Anda's local storage — sama plain format digunakan oleh CSV dan JSON exports, sehingga Anda data adalah tidak pernah locked di. Belajar mode menampilkan satu kartu di waktu dan menyimpan dua piles: diketahui dan still-learning. Shuffling uses acak reordering dari set kartu sehingga Anda cannot memorise urutan instead dari jawaban. cetak view lays setiap kartu out di grid dengan numbered fronts dan backs, sehingga dicetak halaman becomes atur dari kertas kartu di detik.

Pertanyaan yang Sering Diajukan

Bagaimana cara membuat kartu flash yang baik?

Simpan satu idea per kartu: pendek pertanyaan, suku atau prompt di front dan pendek, persis jawaban di kembali. "Apa adalah capital dari France?" berfungsi lebih baik than paragraph. Jika jawaban has tiga bagian, buat tiga kartu.

Where adalah my set kartu saved?

Di Anda sendiri browser's local storage, di ini perangkat hanya. Nothing adalah uploaded. Jika Anda clear Anda browser's site data, saved set kartu adalah deleted — sehingga export penting set kartu sebagai CSV atau JSON files sebagai backup.

Apa format adalah CSV dan JSON exports?

CSV exports have front,kembali header baris dan standard quoting, sehingga mereka buka di Excel, Google Sheets, Anki-style importers dan paling flashcard apps. JSON exports contain set kartu nama dan kartu array dengan front/kembali fields. Anda can import either format kembali ke dalam ini alat.

Bagaimana does tahu / don't-know melacak membantu?

Ketika Anda nilai kartu "Masih belajar", itu stays di Anda ulasan pile; "Tahu itu" kartu adalah atur aside. Di akhir dari ronde Anda can restart dengan hanya kartu Anda missed — ini adalah retrieval latihan focused tepat where Anda perlu itu, tercepat cara untuk tutup selisih sebelum ujian.

Apa adalah Spaced Ulasan (SM-2) mode?

Itu schedules Anda kartu cara Anki does. Rate setiap reviewed kartu Lagi, Sulit, Baik atau Mudah; SM-2 algorithm lalu brings itu kembali setelah bertumbuh intervals - 1 hari, 6 hari, lalu longer - sehingga Anda ulasan setiap kartu saja sebelum Anda would forget itu. Due kartu adalah picked secara otomatis setiap hari, dan progress adalah saved per set kartu di browser Anda.

Can I cetak flashcards untuk gunakan di kertas?

Yes — gunakan Cetak Kartu button. Kartu adalah laid out di two-column grid dengan fronts dan backs listed di urutan, ready untuk cut out. Untuk double-sided kertas kartu, tulis matching angka di kembali.
