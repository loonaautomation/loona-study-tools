猜词游戏 — 逐字母猜单词

简而言之: 选择一个单词列表——动物、科学、地理、学校单词或您自己的列表——玩经典的猜词游戏:在屏幕键盘上猜字母,在六次错误猜测完成绘图之前揭晓单词。

猜词游戏仍然是课堂的最爱,因为每次猜测都是一次小小的拼写决定,全班都可以喊出建议。内置列表意味着教师可以在一节课结束时几秒内开始游戏。

🔒 天生私密: 自定义单词只在本设备上使用,永不存储或上传。

如何使用

  1. 选择一个列表 或按"使用我自己的单词",每行输入一个单词(字母 a–z)。
  2. 按新单词 — 一个单词被随机选出并显示为空格。
  3. 点击字母 在键盘上。正确的字母出现在单词中;错误的消耗六条生命之一并给绘图添加一条线。
  4. 获胜 通过完成单词,或随时按新单词进行新游戏。

工作原理

游戏状态由单词加上猜测字母列表计算:显示的模式、错误猜测计数和赢/输在每次猜测后重新推导,这使绘图、键盘和消息完全同步。每轮从所选列表中随机挑选单词。

常见问题

为什么自定义列表只用字母 a–z?

屏幕键盘涵盖 a–z 和空格,这使游戏简单快速,适合课堂使用。带重音或其他文字的单词在此版本中不受支持。

允许猜错多少次?

六个,如经典游戏——头、身体、两条手臂和两条腿。

两名学生可以一起玩吗?

是的——一个学生可以选择"我自己的单词",输入一个秘密单词,然后把设备交出。该单词在游戏结束前永不显示。
