打字学习导师 — 真正的课程，不只是测试

简而言之： 这位导师一步一步教您打字：十二个短课程带您从主行到整个键盘 — 包括大写字母和数字 — 同时屏幕键盘会点亮每一个下一个键。以 85% 或更高的准确率完成一课即可解锁下一课。

打字测试只会测量您；它从不教您。这位导师是另一半：一个耐心的课程，一次介绍几个键，练习到感觉轻松为止，跟踪您个人会按错哪些键，并且只在您准备好时才继续。还有一个温和的儿童模式，课程更短，还有星星奖励。当您之后想测量速度时，可以参加 Loona Text Tools 上的打字测试 — 先在这里学习。

如何使用

  1. 选择一课 — 从第 1 课（拉丁键盘的主行）开始。锁定的课程会在您通过前面的课程时逐个打开。
  2. 输入发光的字母 — 屏幕键盘会点亮下一个要按的确切按键，让您的手指学会每个键的位置。
  3. 按错键不会让您前进 — 按正确的键继续。错误会计入您的准确率，并记录在您的按键准确率面板中。
  4. 以 85% 或更高的准确率完成（儿童模式为 75%）即可解锁下一课，并查看该课的 WPM 和准确率。
  5. 每天回来 — 每天十分钟的课程比一次长时间的练习更快地建立真正的盲打能力。

工作原理

本课程遵循打字学校使用的经典盲打顺序：先是主行（手指的家），然后是顶行，然后是底行，然后是用 Shift 的大写字母，最后是数字和完整的句子。每课只增加几个新键，并将它们与您已经知道的键混合，这正是肌肉记忆形成的方式。导师会跟踪每个键的每一次击键，因此按键准确率面板可以显示您个人的弱键 — 那些值得多练习一轮的键。

常见问题

这与打字测试有什么不同？

测试会给您一段文字和一个分数 — 它假设您已经会打字了。这位导师是来教的：它一次介绍两个键，进行练习，在屏幕键盘上显示下一个键，跟踪您个人容易出错的键，并按顺序解锁课程。先在这里学习；然后当您觉得准备好时，再用 Loona Text Tools 上的打字测试来测量自己。

什么是儿童模式？

为孩子们准备的更短、更温和的路径：六个迷你课程，每课文字更少，目标大而友好，还有星星奖励。孩子们以 75% 而不是 85% 的准确率解锁下一课，因为在这个年龄，鼓励比压力更重要。

WPM 和准确率是如何计算的？

准确率是正确击键数除以所有击键数，包括错误。WPM 使用每词 5 个字符的标准打字惯例，只计算正确输入的字符，时间为从第一次击键到最后一次击键。按错键永远不会让您前进 — 您需要按正确的键才能继续，就像真正的盲打练习一样。

我的进度会被保存吗？

是的 — 仅在此设备上。您已解锁的课程、最佳成绩和每个键的准确率都存储在浏览器的本地存储中，从不存储在服务器上，也从不与任何人共享。使用重置所有进度即可清除它们。
