考试日期表制作工具 — 整洁、可直接打印的考试日程表

简而言之： 输入学校名称、班级和考试名称，为每一场考试添加一行——日期、科目、时间和考场——本工具会自动填入星期几，自动按日期顺序排列试卷，并打印出一张整洁的 A4 日期表，您可以张贴或分发。

日期表是每位学生、家长和老师都会反复查看的一份考试文件——因此它必须清晰、正确且易于打印。这个免费制作工具为您完成这一切：星期几由日期计算得出（从不手动输入，因此不会出错），试卷始终按日期顺序排列，打印出的表格整洁规范，带有学校标题和给学生的说明，是一张标准的 A4 表格。

🔒 注重隐私的设计：您的日期表仅在此设备上生成。它只保存在此浏览器中（以便您回来继续编辑），从不上传到任何服务器。

考试科目安排

您输入时，工作内容会自动保存在此浏览器中，因此您可以关闭页面后再回来继续。使用“保存 / 载入 / 清空”按钮可自行管理保存的副本。

如何使用

  1. 填写表头： 您的学校名称、班级或年级、考试名称（例如“2027 年期末考试”）以及学年或年度。这些内容会显示在打印日期表的顶部。
  2. 每一场考试添加一行： 选择日期——星期几会自动填入——然后输入科目、考试开始和结束时间，以及可选的考场或监考备注。
  3. 排列试卷顺序： 开启自动排序后，试卷会自动按日期顺序排列。如果需要手动排序，请关闭自动排序，并使用上移和下移按钮，以及“复制”和“删除”来调整各行。
  4. 填写说明： 添加学生必须遵守的注意事项——报到时间、需要携带的物品、禁止携带的物品。这些说明会打印在表格下方。
  5. 打印或另存为 PDF： 点击“打印 / 另存为 PDF”。只有日期表本身会以 A4 格式打印——编辑器、按钮和菜单不会出现在纸面上。

工作原理

每场考试的星期几是根据您选择的日期，利用您自己设备上的日历计算出来的——从不手动输入，因此日期表绝不会在日期旁显示错误的星期。开启自动排序后，每当您更改日期，各行都会按日期重新排序；没有日期的试卷会排在末尾。所有操作都在您的浏览器中完成：工作时日期表会自动保存到此浏览器的本地存储中，不会发送到任何服务器。打印视图会将您的内容重新整理成一张整洁的表格——日期、星期、科目、时间和考场/备注——置于学校标题之下，说明文字位于表格下方。

常见问题

星期几真的是自动的吗？

是的。选择一个日期，正确的星期几会立即显示在旁边，由该日期计算得出。更改日期，星期几也会随之更新，因此星期与日期永远不会不一致。

可以关闭按日期排序吗？

可以——取消勾选“按日期自动排序”，各行就会保持您留下的确切顺序。使用每行上的上移和下移按钮即可手动排列。

我的日期表会被保存吗？

会，仅保存在此浏览器中。本工具会在您输入时自动保存，而“保存”、“载入已保存的日期表”和“全部清空”按钮让您可以自行管理这份保存的副本。任何内容都不会被上传，清除保存的副本会将其从此浏览器中删除。

打印出的日期表是什么样子？

一张整洁的 A4 纸：学校名称作为标题，下方是考试、班级和学年一行，接着是包含日期、星期、科目、时间和考场/备注列的表格，底部是给学生的说明。只有日期表会被打印——任何编辑控件都不会出现在纸面上。

同一天可以安排两场考试吗？

可以——您可以添加任意多行，包括同一日期的上午和下午考试。为每场考试分别设置开始和结束时间，如有需要，还可以设置不同的考场。
