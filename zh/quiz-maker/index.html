测验制作工具 — 构建带即时计分和可打印答案的测验

简而言之: 构建带选择题、对/错和简答题的测验,然后让学生在屏幕上尝试,带即时计分和完整的答案回顾——或者打印测验和单独答案用于纸上测试。以 JSON 导出和导入测验。

手工批改全班的测验会吃掉一个晚上。在下面构建一次测验:学生可以在任何手机或电脑上作答,立即得到分数和复习,或者您可以打印出来用于课堂,把答案留给自己。

如何使用测验制作工具

  1. 为您的测验命名 并选择一个问题类型:选择题、对/错或简答。
  2. 写出问题。 对于多项选择题,填写全部四个选项并选择哪一个是正确的。对于简答题,您可以添加用 | 分隔的备选答案。
  3. 添加每一道题目 — 它们出现在列表中,您可以在其中删除任何一个。
  4. 运行它: 学生在尝试部分回答,按提交查看他们的分数和逐题复习。
  5. 或者改用纸笔: 打印测验会生成一份干净的试卷(带姓名和日期行);打印答案会单独打印答案以供批改。
  6. 保留它: 导出 JSON 把整个测验保存为一个文件,您可以下学期重新导入或与同事分享。

工作原理

您的测验以结构化数据存储在浏览器中:标题加问题列表,每个问题有其类型、文本和正确答案。尝试模式把问题呈现为表单;提交时,一个小的计分引擎比较每个答案——对选择题和对/错精确比较,对简答在规范大写字母和间距后比较——然后构建复习,把每个问题标记为对或错,并显示正确答案。打印视图由相同数据生成:测验纸有意省略答案,而答案按顺序列出它们。

常见问题

我可以使用什么问题类型?

三种:带四个选项的选择题(您标记正确的一个)、对/错和简答。对于简答,检查对大小写字母和多余空格宽容,您可以用 | 字符分隔几个可接受的答案——例如 美国 | United States | America.

测验如何计分?

每道题一分。多项选择和对/错题精确核对;简答题在整理大小写和空格后比较。提交后,学生会看到他们的分数和完整的复习,显示每道题的正确答案。

我可以打印测验用于纸笔测试吗?

是的——提供了两个打印按钮。"打印测验"打印问题,带姓名、日期和书面答案的空间,不显示答案。"打印答案"为教师打印单独的答案。分开打印它们,使答案永不到达学生手中。

我的测验保存在哪里,我可以重用它吗?

您正在构建的测验会自动保存在此设备的浏览器中。使用导出 JSON 把永久副本保存为文件,与另一位老师分享,或用导入 JSON 在不同设备上加载。

学生会在作答模式下偷看答案作弊吗?

答案只在学生提交后、在复习环节中显示。与任何在设备上运行的工具一样,有决心的学生可以检查页面代码——因此对于高利害考试,请改用打印的测验。
