化学方程式配平工具 — 已配平,并经证明已配平

简而言之: 输入一个带箭头 ( -> ) 的未配平方程式,获得使其配平的最小整数系数——然后是原子检查,显示每种元素在两边的计数,因此您可以看到配平是真实的。

试错配平在燃烧和氧化还原方程式出现之前还管用。本配平工具精确求解背后的方程组——与化学家软件所用的线性代数相同——然后通过重新计数每个原子来证明答案。

🔒 天生私密: 方程在本设备上求解;什么都不存储或上传。

如何使用

  1. 输入方程: 物质用 + 分隔,两边用 ->。按需要使用正确的元素符号和括号:例如 Fe + O2 -> Fe2O3, Ca(OH)2 + HCl -> CaCl2 + H2O.
  2. 省去您可能已输入的任何系数 — 或包括它们;现有数字被忽略并重新计算。
  3. 读出配平的方程式 以及其下方的原子检查:每种元素必须在两边显示相同的数量——这种相等就是配平的定义。

工作原理

每种物质都被解析为原子计数(与摩尔质量计算器相同的解析器)。配平是每种元素一个方程的方程组;它用分数运算精确求解(高斯消元——没有小数,没有四舍五入),自由变量被缩放为最小的正整数。如果输入无解,或暗中结合了两个独立的反应,工具会如实说明,而不是编造系数。显示之前,最后一次对两边原子的独立重新计数会验证每个结果。

常见问题

为什么要最小整数?

惯例:2H2 + O2 → 2H2O,而不是 4H2 + 2O2 → 4H2O,尽管两者都配平。本工具会用最大公约数约减系数,与教科书风格一致。

它能配平离子方程式或半反应方程式吗?

它配平完整的分子方程式。不跟踪电荷,因此带电子(e−)的离子半反应方程式不在其范围内——请用您正在学习的半反应方法配平那些,用本工具核对完整方程式。

它显示'不止一个独立的解'。这是什么意思?

您的方程式可以以真正不同的方式配平——通常是因为它把两个独立的反应粘在一起(一个经典案例是碳燃烧成 CO 和 CO2)。把它拆成两个真实的反应,分别配平每一个。
