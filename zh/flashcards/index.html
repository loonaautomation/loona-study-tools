抽认卡制作工具 — 免费创建、学习和打印抽认卡

简而言之: 输入正面和背面添加一张卡片,构建整个卡组,然后用翻卡、洗牌和知道/不知道跟踪学习它。卡组在您的浏览器中自动保存,您可以以 CSV 或 JSON 导出或导入它们,或打印在纸上。

抽认卡有效是因为它们强迫回忆:您看到问题,努力想出答案,然后自我检查。正是这种努力建立了记忆。在下面为任何科目构建一个卡组——词汇、日期、公式、定义——并以短轮次学习,只保留您答错的卡片继续轮换。

🔒 天生私密: 您的卡组只存储在此浏览器、本设备上。什么都不上传到服务器。

学习模式

先在上面添加至少一张卡片,然后在这里开始学习。

间隔复习 (SM-2) - 长期记忆模式

上面的学习模式适合临时抱佛脚。此模式像 Anki 一样安排复习:给每张卡片评分 再来 / 难 / 好 / 简单 卡片在 1 天、6 天后回来,然后间隔越来越长。卡片只在它们 到期,因此每天的学习只需几分钟。进度会按卡组保存在这个浏览器中。

如何使用抽认卡制作工具

  1. 给您的卡组命名 — 例如 "Biology Chapter 4"——这样您以后能再找到它。
  2. 添加卡片: 在正面输入问题或术语,在背面输入答案,然后按添加卡片。重复;卡片出现在列表中,您可以编辑或删除它们。
  3. 学习: 在学习模式中,阅读正面,在脑中说出答案,然后点击卡片(或翻面)检查。诚实——这种诚实使跟踪有用。
  4. 给自己分类: 每张卡片按"已掌握"或"仍在学习"。本轮结束时,只用漏掉的卡片重新开始,直到一张不剩。
  5. 保存 & 分享: 卡组在本浏览器中自动保存。使用导出 CSV/JSON 备份卡组或发送给同学,使用导入加载回来。

工作原理

制作工具把每个卡组存储为浏览器本地存储中的正/反面配对的简单列表——与 CSV 和 JSON 导出使用的相同纯格式,因此您的数据永不被锁定。学习模式一次显示一张卡片,保留两堆:已掌握和仍在学习。洗牌使用卡组的随机重排,因此您无法记住顺序而不是答案。打印视图把每张卡片以网格布局,带编号的正面和背面,因此打印页面在几秒钟内变成一套纸卡片。

常见问题

我怎样制作一张好的抽认卡?

每张卡只放一个想法:正面放一个简短的问题、术语或提示,背面放一个简短、确切的答案。"What is the capital of France?" 比一段话效果好。如果一个答案有三个部分,就做三张卡。

我的卡组保存在哪里?

在您自己浏览器的本地存储中,仅限本设备。不上传任何内容。如果您清除了浏览器的站点数据,已保存的卡组会被删除——因此请将重要卡组导出为 CSV 或 JSON 文件作为备份。

CSV 和 JSON 导出是什么格式?

CSV 导出有一个 front,back 标题行和标准引用,因此它们在 Excel、Google Sheets、Anki 式导入器和大多数抽认卡应用中打开。JSON 导出包含卡组名称和带 front/back 字段的 cards 数组。您可以把任一格式导入回本工具。

会/不会跟踪有什么帮助?

当您把一张卡片标记为"仍在学习"时,它留在您的复习堆中;"已掌握"的卡片被放在一边。一轮结束时,您可以只用漏掉的卡片重新开始——这是恰好聚焦在您需要之处的提取练习,是考试前弥合差距的最快方法。

什么是间隔复习 (SM-2) 模式?

它像 Anki 一样安排您的卡片。给每张复习过的卡片评为再来、难、好或简单;然后 SM-2 算法会以逐渐增长的间隔把它带回来——1 天、6 天,然后更长——让您在即将忘记之前复习每张卡片。每天自动挑出到期卡片,进度按卡组保存在您的浏览器中。

我可以打印抽认卡在纸上使用吗?

是的——使用打印卡片按钮。卡片以两列网格布局,正面和背面按顺序列出,可随时剪下。对于双面纸卡片,在背面写匹配的数字。
