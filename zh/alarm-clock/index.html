如何使用

  1. 选择时间: 使用闹钟时间栏选择闹钟应响铃的时间。如果该时间今天已经过去,闹钟会自动设为明天。
  2. 添加标签和铃声: 给闹钟起个名字,如“起床”或“下课”,然后从四种铃声中选择一种 — 经典蜂鸣声、温和铃声、电子闹钟声或柔和钟声。按试听铃声可以先听一听。
  3. 按添加闹钟: 闹钟会出现在“我的闹钟”中,并带有自己的开关。想加多少个都可以 — 起床闹钟、学习休息闹钟和上课闹钟可以并排共存。
  4. 保持此标签页打开: 闹钟从此标签页响铃,所以请让页面保持打开(可以使用其他标签页)。使用全屏可获得大的床头或教室显示效果;如果浏览器支持,打开“保持屏幕常亮”可让显示屏保持亮起。
  5. 响铃时: 响铃面板会出现,铃声循环播放,页面标题闪烁。按小睡 5 分钟或小睡 10 分钟可稍后再提醒一次,或按关闭停止。被关闭的闹钟会自动关闭开关,并顺延到明天的同一时间,随时可以再次打开。
  6. 闹钟会被记住: 闹钟和你的 12/24 小时制选择保存在此浏览器中,因此在同一设备上重新打开页面时它们还在。

工作原理

实时时钟取自你设备自身的时钟,每秒刷新四次,因此始终显示你真实的本地时间。每个闹钟都保存了它下一次应响铃的确切时刻;页面每秒多次将该时刻与设备时钟核对,这意味着即使标签页当时很忙,闹钟也不会漂移。四种铃声使用 Web Audio API 实时合成 — 用振荡器塑造成蜂鸣声、铃声和钟声 — 因此没有音频文件需要下载,页面加载后离线也能发声。你的闹钟和设置只保存在此设备上浏览器的本地存储中;不会发送到任何服务器。在浏览器提供 Screen Wake Lock API 的情况下,“保持屏幕常亮”按钮会请求它阻止屏幕休眠,当你回到标签页时会自动重新请求锁定。

常见问题

如果我关闭标签页,闹钟还会响吗?

不会。这是一个网页,不是已安装的应用,因此只有在标签页打开时才能响铃 — 保持此标签页打开,闹钟就会在设定时间从此标签页响铃。如果需要在关闭一切后仍能响铃,请把手机自带的时钟应用作为备用。

为什么没有声音?

检查三件事:设备没有静音或处于勿扰模式、浏览器标签页没有被静音(右键单击标签页检查),并且你至少与页面互动过一次 — 浏览器只允许在点按或点击之后播放声音,这就是为什么先按添加闹钟或试听铃声很重要。然后按试听铃声确认音频正常,再放心依赖闹钟。

我可以设定不止一个闹钟吗?

可以 — 想设多少个都可以。每个闹钟都有自己的时间、标签、铃声和开关,因此你可以保留一整天的提醒,逐个打开或关闭,而无需删除。

我可以在手机上使用吗?

可以。本页面可在手机、平板和电脑上使用,大显示屏远距离也易于阅读,全屏模式可把它变成床头式时钟。保持标签页打开;如果浏览器支持,打开“保持屏幕常亮”,让显示屏不会休眠。用作晨间闹钟时,建议整夜给手机充电。

我的闹钟会被保存吗?

会 — 保存在此浏览器、此设备上。你的闹钟和 12/24 小时制偏好存储在本地存储中,重新打开页面时仍然存在。它们不会同步到其他设备或浏览器,清除浏览器的网站数据会将它们删除。
