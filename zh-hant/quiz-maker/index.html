測驗製作工具 — 構建帶即時計分和可列印答案的測驗

簡而言之: 構建帶選擇題、對/錯和簡答題的測驗,然後讓學生在螢幕上嘗試,帶即時計分和完整的答案回顧——或者列印測驗和單獨答案用於紙上測試。以 JSON 匯出和匯入測驗。

手工批改全班的測驗會吃掉一個晚上。在下面構建一次測驗:學生可以在任何手機或電腦上作答,立即得到分數和複習,或者您可以列印出來用於課堂,把答案留給自己。

🔒 天生私密: 您的測驗只構建並儲存在此瀏覽器、本裝置上。什麼都不上傳。

如何使用測驗製作工具

  1. 為您的測驗命名 並選擇一個問題型別:選擇題、對/錯或簡答。
  2. 寫出問題。 對於多項選擇題,填寫全部四個選項並選擇哪一個是正確的。對於簡答題,您可以新增用 | 分隔的備選答案。
  3. 新增每一道題目 — 它們出現在列表中,您可以在其中刪除任何一個。
  4. 執行它: 學生在嘗試部分回答,按提交檢視他們的分數和逐題複習。
  5. 或者改用紙筆: 列印測驗會生成一份乾淨的試卷(帶姓名和日期行);列印答案會單獨列印答案以供批改。
  6. 保留它: 匯出 JSON 把整個測驗儲存為一個檔案,您可以下學期重新匯入或與同事分享。

工作原理

您的測驗以結構化資料儲存在瀏覽器中:標題加問題列表,每個問題有其型別、文字和正確答案。嘗試模式把問題呈現為表單;提交時,一個小的計分引擎比較每個答案——對選擇題和對/錯精確比較,對簡答在規範大寫字母和間距後比較——然後構建複習,把每個問題標記為對或錯,並顯示正確答案。列印檢視由相同資料生成:測驗紙有意省略答案,而答案按順序列出它們。

常見問題

我可以使用什麼問題型別?

三種:帶四個選項的選擇題(您標記正確的一個)、對/錯和簡答。對於簡答,檢查對大小寫字母和多餘空格寬容,您可以用 | 字元分隔幾個可接受的答案——例如 美國 | United States | America.

測驗如何計分?

每道題一分。多項選擇和對/錯題精確核對;簡答題在整理大小寫和空格後比較。提交後,學生會看到他們的分數和完整的複習,顯示每道題的正確答案。

我可以列印測驗用於紙筆測試嗎?

是的——提供了兩個列印按鈕。"列印測驗"列印問題,帶姓名、日期和書面答案的空間,不顯示答案。"列印答案"為教師列印單獨的答案。分開列印它們,使答案永不到達學生手中。

我的測驗儲存在哪裡,我可以重用它嗎?

您正在構建的測驗會自動儲存在此裝置的瀏覽器中。使用匯出 JSON 把永久副本儲存為檔案,與另一位老師分享,或用匯入 JSON 在不同裝置上載入。

學生會在作答模式下偷看答案作弊嗎?

答案只在學生提交後、在複習環節中顯示。與任何在裝置上執行的工具一樣,有決心的學生可以檢查頁面程式碼——因此對於高利害考試,請改用列印的測驗。
