Loona CPS Test — 你每秒能點擊多少次？

簡而言之： 選擇一個時間（1–60 秒），然後盡可能快地點擊或點按大面板。測試從您的第一次點擊開始，並報告您的每秒點擊次數 (CPS)、總點擊次數和速度等級。還為鍵盤玩家提供了空白鍵計數器模式。

CPS — 每秒點擊次數 — 是衡量點擊速度最簡單的方法，遊戲玩家、學生和任何喜歡快速挑戰的人都用它來測試反應能力並追蹤進步。這個免費測試對滑鼠和觸控都能正常運作，因此您的手機成績也能逐次點按公平計數。您的結果、個人最佳成績和歷史記錄都保留在您的裝置上 — 不上傳任何內容，也無需註冊。

使用方法

  1. 選擇模式 — 用滑鼠或手指進行點擊測試，或用鍵盤使用空白鍵計數器（在觸控螢幕上，在空白鍵模式下點按面板也會計數）。
  2. 選擇時間 — 1、5、10、30 或 60 秒。短測試測量爆發速度；長測試測量耐力。
  3. 盡可能快地點擊、點按或按空白鍵。計時器從您的第一次按下開始，因此無需等待倒數計時。
  4. 查看結果 — 總點擊次數、精確到小數點後兩位的 CPS 以及您的速度等級。
  5. 打破自己的最佳成績 — 您每種模式的個人最佳成績都保存在下方，歡迎回來嘗試超越它。

運作原理

計時器從您的第一次按下開始，並使用高精度效能計時進行測量，因此結果準確反映所選的完整時長。滑鼠和觸控的點擊每次按下只計數一次 — 一次點按永遠不會被重複計數。到達速度快得不可能的按下（間隔低於 18 毫秒，比人類手指的移動速度還快）不予計數，如果有任何按下被過濾掉，結果會清楚地告訴您有多少。您的分數、個人最佳成績和最近歷史記錄僅保存在瀏覽器的 localStorage 中 — 任何內容都不會離開您的裝置。

常見問題

什麼是 CPS？

CPS 是 clicks per second（每秒點擊次數）的縮寫：完成的點擊（或點按，或空白鍵按下）次數除以測試的秒數。10 秒測試點擊 63 次，得到 6.30 CPS。

多少 CPS 算好成績？

大多數人的成績在 4 到 7 CPS 之間。5–6 左右高於平均水準，8 或以上速度極快，10+ 是閃電般的速度。請參閱本頁的等級表 — 並記住這些等級只是參考指南，不是科學標準。

這個 CPS 測試能在手機上使用嗎？

可以。觸控每次點按只計數一次，不會重複計數，因此手機和平板電腦的成績公平。面板使用單一的統一指標事件，這意味著一次點按始終等於一次點擊。

為什麼有些點擊沒有被計數？

為了保持結果公平且可比，間隔低於 18 毫秒 — 比人類手指物理上能移動的速度還快 — 到達的按下不予計數。如果有任何按下被過濾掉，您的結果會顯示一條簡短說明，告知數量。普通的快速點擊永遠不會受到影響。

我的資料儲存在哪裡？

僅儲存在此瀏覽器中。您的個人最佳成績和最近結果保存在您自己裝置上的 localStorage 中，以便您可以追蹤進度；任何內容都不會上傳到伺服器，您可以隨時使用「清除歷史記錄」按鈕刪除所有內容。
