化學方程式配平工具 — 已配平,並經證明已配平

簡而言之: 輸入一個帶箭頭 ( -> ) 的未配平方程式,獲得使其配平的最小整數係數——然後是原子檢查,顯示每種元素在兩邊的計數,因此您可以看到配平是真實的。

試錯配平在燃燒和氧化還原方程式出現之前還管用。本配平工具精確求解背後的方程組——與化學家軟體所用的線性代數相同——然後透過重新計數每個原子來證明答案。

🔒 天生私密: 方程在本裝置上求解;什麼都不儲存或上傳。

如何使用

  1. 輸入方程: 物質用 + 分隔,兩邊用 ->。按需要使用正確的元素符號和括號:例如 Fe + O2 -> Fe2O3, Ca(OH)2 + HCl -> CaCl2 + H2O.
  2. 省去您可能已輸入的任何係數 — 或包括它們;現有數字被忽略並重新計算。
  3. 讀出配平的方程式 以及其下方的原子檢查:每種元素必須在兩邊顯示相同的數量——這種相等就是配平的定義。

工作原理

每種物質都被解析為原子計數(與摩爾質量計算器相同的解析器)。配平是每種元素一個方程的方程組;它用分數運算精確求解(高斯消元——沒有小數,沒有四捨五入),自由變數被縮放為最小的正整數。如果輸入無解,或暗中結合了兩個獨立的反應,工具會如實說明,而不是編造係數。顯示之前,最後一次對兩邊原子的獨立重新計數會驗證每個結果。

常見問題

為什麼要最小整數?

慣例:2H2 + O2 → 2H2O,而不是 4H2 + 2O2 → 4H2O,儘管兩者都配平。本工具會用最大公約數約減係數,與教科書風格一致。

它能配平離子方程式或半反應方程式嗎?

它配平完整的分子方程式。不跟蹤電荷,因此帶電子(e−)的離子半反應方程式不在其範圍內——請用您正在學習的半反應方法配平那些,用本工具核對完整方程式。

它顯示'不止一個獨立的解'。這是什麼意思?

您的方程式可以以真正不同的方式配平——通常是因為它把兩個獨立的反應粘在一起(一個經典案例是碳燃燒成 CO 和 CO2)。把它拆成兩個真實的反應,分別配平每一個。
