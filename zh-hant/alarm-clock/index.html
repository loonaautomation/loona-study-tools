線上鬧鐘 — 大顯示屏、多個鬧鐘與小睡功能

簡而言之: 一款免費線上鬧鐘:超大即時時鐘,需要多少個鬧鐘都可以 — 每個鬧鐘都有自己的標籤和鈴聲 — 還有 5 分鐘和 10 分鐘小睡。鬧鐘保存在此瀏覽器中,從此分頁響鈴,無需註冊,也無需安裝任何東西。

大多數鬧鐘應用程式都要求註冊帳號、安裝軟體或提供你的資料。這款全都不需要:開啟頁面,設定鬧鐘,讓分頁保持開啟即可。大顯示屏還可以當作書桌、教室或床頭時鐘,隔著房間也能看清;每個鬧鐘都有自己的標籤、鈴聲和開關。

如何使用

  1. 選擇時間: 使用鬧鐘時間欄選擇鬧鐘應響鈴的時間。如果該時間今天已經過去,鬧鐘會自動設為明天。
  2. 新增標籤和鈴聲: 給鬧鐘起個名字,如「起床」或「下課」,然後從四種鈴聲中選擇一種 — 經典蜂鳴聲、溫和鈴聲、電子鬧鐘聲或柔和鐘聲。按試聽鈴聲可以先聽一聽。
  3. 按新增鬧鐘: 鬧鐘會出現在「我的鬧鐘」中,並帶有自己的開關。想加多少個都可以 — 起床鬧鐘、學習休息鬧鐘和上課鬧鐘可以並排共存。
  4. 保持此分頁開啟: 鬧鐘從此分頁響鈴,所以請讓頁面保持開啟(可以使用其他分頁)。使用全螢幕可獲得大的床頭或教室顯示效果;如果瀏覽器支援,開啟「保持螢幕常亮」可讓顯示屏保持亮起。
  5. 響鈴時: 響鈴面板會出現,鈴聲循環播放,頁面標題閃爍。按小睡 5 分鐘或小睡 10 分鐘可稍後再提醒一次,或按關閉停止。被關閉的鬧鐘會自動關閉開關,並順延到明天的同一時間,隨時可以再次開啟。
  6. 鬧鐘會被記住: 鬧鐘和你的 12/24 小時制選擇保存在此瀏覽器中,因此在同一裝置上重新開啟頁面時它們還在。

工作原理

即時時鐘取自你裝置自身的時鐘,每秒重新整理四次,因此始終顯示你真實的本地時間。每個鬧鐘都保存了它下一次應響鈴的確切時刻;頁面每秒多次將該時刻與裝置時鐘核對,這意味著即使分頁當時很忙,鬧鐘也不會漂移。四種鈴聲使用 Web Audio API 即時合成 — 用振盪器塑造成蜂鳴聲、鈴聲和鐘聲 — 因此沒有音訊檔案需要下載,頁面載入後離線也能發聲。你的鬧鐘和設定只保存在此裝置上瀏覽器的本地儲存中;不會傳送到任何伺服器。在瀏覽器提供 Screen Wake Lock API 的情況下,「保持螢幕常亮」按鈕會請求它阻止螢幕休眠,當你回到分頁時會自動重新請求鎖定。

常見問題

如果我關閉分頁,鬧鐘還會響嗎?

不會。這是一個網頁,不是已安裝的應用程式,因此只有在分頁開啟時才能響鈴 — 保持此分頁開啟,鬧鐘就會在設定時間從此分頁響鈴。如果需要在關閉一切後仍能響鈴,請把手機內建的時鐘應用程式作為備用。

為什麼沒有聲音?

檢查三件事:裝置沒有靜音或處於勿擾模式、瀏覽器分頁沒有被靜音(在分頁上按右鍵檢查),並且你至少與頁面互動過一次 — 瀏覽器只允許在點按或點擊之後播放聲音,這就是為什麼先按新增鬧鐘或試聽鈴聲很重要。然後按試聽鈴聲確認音訊正常,再放心依賴鬧鐘。

我可以設定不止一個鬧鐘嗎?

可以 — 想設多少個都可以。每個鬧鐘都有自己的時間、標籤、鈴聲和開關,因此你可以保留一整天的提醒,逐個開啟或關閉,而無需刪除。

我可以在手機上使用嗎?

可以。本頁面可在手機、平板和電腦上使用,大顯示屏遠距離也易於閱讀,全螢幕模式可把它變成床頭式時鐘。保持分頁開啟;如果瀏覽器支援,開啟「保持螢幕常亮」,讓顯示屏不會休眠。用作晨間鬧鐘時,建議整夜給手機充電。

我的鬧鐘會被保存嗎?

會 — 保存在此瀏覽器、此裝置上。你的鬧鐘和 12/24 小時制偏好儲存在本地儲存中,重新開啟頁面時仍然存在。它們不會同步到其他裝置或瀏覽器,清除瀏覽器的網站資料會將它們刪除。
