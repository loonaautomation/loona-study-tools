フラッシュカードメーカー — 無料でフラッシュカードを作成、学習 & 印刷

要するに： カードを追加するには表と裏を入力し、デッキ全体を構築し、それからめくるカード、シャッフル、知っている／知らない の追跡で学習してください。デッキはブラウザに自動的に保存され、CSV または JSON としてエクスポートやインポートができ、紙に印刷もできます。

フラッシュカードが効果的なのは、想起を強制するからです：問題を見て、答えを思い出そうと奮闘し、それから自分で確認します。その奮闘こそが記憶を築きます。以下のデッキを任意の科目 — 語彙、日付、公式、定義 — で作成し、短いラウンドで学習し、間違えたカードだけをローテーションに残してください。

🔒 設計上プライベート： あなたのデッキは、このデバイス上のこのブラウザにのみ保存されます。何もサーバーにアップロードされません。

学習モード

上にカードを少なくとも一枚追加してから、ここで学習を始めてください。

間隔をあけた復習 (SM-2) - 長期記憶モード

上記の学習モードは詰め込み用です。このモードは Anki のように復習をスケジュールします：各カードを評価してください もう一度 / 難しい / 良い / 簡単 そしてカードは 1 日後、6 日後に戻り、それからますます長い間隔で戻ります。カードは、それが 期限, そのため毎日の学習は数分で済みます。進捗はデッキごとにこのブラウザに保存されます。

フラッシュカードメーカーの使い方

  1. デッキに名前を付けてください — 例えば「生物学 第4章」— 後で再び見つけることができます。
  2. カードを追加： 質問または用語を表に、答えを裏に入力し、それから「カードを追加」を押してください。繰り返してください。カードは、編集や削除ができるリストに現れます。
  3. 学習： 学習モードでは、表を読み、頭の中で答えを言い、それからカード (またはめくる) をクリックして確認してください。正直に — その正直さが、追跡を有用なものにします。
  4. 自分で分類してください： すべてのカードについて「知っている」または「まだ学習中」を押してください。ラウンドが終わったら、間違えたカードだけで再開し、一つも残らなくなるまで繰り返してください。
  5. 保存 & 共有： デッキはこのブラウザに自動的に保存されます。CSV/JSON エクスポートを使って、デッキをバックアップしたりクラスメートに送ったりし、インポートを使って読み戻してください。

仕組み

メーカーは、各デッキを、ブラウザのローカルストレージ内の表／裏ペアの単純なリストとして保存します — CSV と JSON のエクスポートで使われるのと同じ平易な形式ですので、あなたのデータがロックインされることは決してありません。学習モードは一度に一枚のカードを表示し、二つの山を保持します：知っているものと、まだ学習中のもの。シャッフルはデッキのランダムな並び替えを使うため、答えの代わりに順序を暗記することはできません。印刷ビューは、すべてのカードを番号付きの表と裏とともにグリッドに配置しますので、印刷されたページは数秒で紙のカードのセットになります。

よくある質問

良いフラッシュカードを作るにはどうすればよいですか？

カード一枚にアイデアを一つ：表には短い質問、用語、プロンプトを、裏には短く正確な答えを。「フランスの首都はどこですか？」は段落よりも効果的です。答えに三つの部分がある場合は、三枚のカードを作ってください。

私のデッキはどこに保存されますか？

あなた自身のブラウザのローカルストレージの中、このデバイス上にのみあります。何もアップロードされません。ブラウザのサイトデータを消去すると、保存されたデッキは削除されます。そのため、大切なデッキはバックアップとして CSV または JSON ファイルでエクスポートしてください。

CSV と JSON のエクスポートはどの形式ですか？

CSV エクスポートには次のものがあります： 表,裏 ヘッダー行と標準的な引用符付きで、Excel、Google スプレッドシート、Anki 式のインポーター、ほとんどのフラッシュカードアプリで開きます。JSON エクスポートには、デッキ名と、表／裏フィールドを持つカードの配列が含まれます。どちらの形式も、このツールにインポートし戻すことができます。

知っている／知らないの追跡はどのように役立ちますか？

カードを「まだ学習中」とマークすると、復習の山に残ります。「知っている」カードは脇に置かれます。ラウンドの終わりに、間違えたカードだけで再開できます — これは、まさに必要な場所に焦点を当てた想起練習であり、試験前にギャップを埋める最速の方法です。

間隔をあけた復習 (SM-2) モードとは何ですか？

Anki と同じ方式でカードをスケジュールします。復習した各カードを「もう一度」「難しい」「良い」「簡単」で評価すると、SM-2 アルゴリズムが間隔を広げながら戻します — 1日、6日、それより長く — そのため、忘れる直前に各カードを復習できます。期限になったカードは毎日自動的に選ばれ、進捗はデッキごとにブラウザに保存されます。

紙で使うためにフラッシュカードを印刷できますか？

はい — 「カードを印刷」ボタンを使ってください。カードは二列のグリッドに配置され、表と裏が順序通り一覧になっており、切り取る準備ができています。両面の紙のカードについては、裏に一致する番号を書いてください。
