オンライン目覚まし時計 — 大きな表示、複数のアラーム＆スヌーズ

要するに： とても大きなライブ時計と、必要なだけ設定できるアラーム（それぞれにラベルとサウンド付き）、さらに5分・10分のスヌーズを備えた無料のオンライン目覚まし時計です。アラームはこのブラウザに保存され、このタブから鳴ります。登録もインストールも不要です。

ほとんどの目覚ましアプリはアカウント、インストール、またはあなたのデータを求めます。このアプリはそのどれも求めません。ページを開いてアラームを設定し、タブを開いたままにするだけです。大きな表示は部屋の向こうからでも読めるデスク時計、教室時計、ベッドサイド時計にもなり、各アラームには独自のラベル、サウンド、オン／オフスイッチがあります。

🔒 設計上プライベート： アラームはこのブラウザ、このデバイスにのみ保存されます。何もアップロードされず、アカウントもありません。このタブを開いたままにしてください — アラームはこのタブから鳴ります。

アラーム

アラームを設定

あなたのアラーム

まだアラームがありません — 上で最初のアラームを設定しましょう。

使い方

  1. 時刻を選ぶ： アラーム時刻の欄で、鳴らしたい時刻を選びます。その時刻が今日すでに過ぎている場合、アラームは自動的に明日に設定されます。
  2. ラベルとサウンドを付ける： 「起床」や「授業終了」などの名前を付け、4つのサウンド — クラシックビープ、優しいチャイム、デジタルアラーム、ソフトベル — から選びます。サウンドを試すを押せば先に聞けます。
  3. アラームを追加を押す： アラームが「あなたのアラーム」に独自のオン／オフスイッチ付きで表示されます。好きなだけ追加できます — 起床アラーム、勉強の休憩アラーム、授業のアラームを並べて置けます。
  4. このタブを開いたままにする： アラームはこのタブから鳴るので、ページを開いたままにしてください（他のタブは使えます）。全画面で大きなベッドサイドや教室の表示になり、ブラウザが対応していれば「画面をスリープさせない」をオンにして表示を点けたままにできます。
  5. 鳴ったら： 鳴動パネルが現れ、サウンドがループし、ページタイトルが点滅します。5分スヌーズまたは10分スヌーズを押せば少し後に再び知らせ、止めるを押せば止まります。止めたアラームは自動でオフになり、明日の同じ時刻に繰り越されるので、いつでもまたオンにできます。
  6. アラームは記憶されます： アラームと12／24時間表示の選択はこのブラウザに保存されるため、同じデバイスでページを開き直しても残っています。

仕組み

ライブ時計はあなたのデバイス自体の時計から描画され、1秒に4回更新されるため、常に実際のローカル時刻を表示します。各アラームは次に鳴るべき正確な瞬間を保存しています。ページはその瞬間をデバイスの時計と1秒に数回照合するため、タブが忙しくてもアラームがずれることはありません。4つのサウンドは Web Audio API でライブ合成されます — 発振器をビープ、チャイム、ベルの形に整えたもの — そのためダウンロードする音声ファイルがなく、ページが読み込まれればオフラインでも鳴ります。アラームと設定はこのデバイスのブラウザのローカルストレージにのみ保存され、サーバーには何も送信されません。ブラウザが Screen Wake Lock API を提供する場合、「画面をスリープさせない」ボタンは画面のスリープを止めるよう要求し、タブに戻ると自動的に再要求されます。

よくある質問

タブを閉じてもアラームは鳴りますか？

いいえ。これはインストールされたアプリではなくウェブページなので、タブが開いている間だけ鳴ります — このタブを開いたままにすれば、設定時刻にこのタブから鳴ります。すべてを閉じた後にもアラームが必要な場合は、スマートフォン標準の時計アプリを予備として使ってください。

音が出ないのはなぜですか？

3つ確認してください：デバイスがミュートやおやすみモードになっていないこと、ブラウザのタブがミュートされていないこと（タブを右クリックして確認）、そしてページで少なくとも一度操作したことです — ブラウザはタップやクリックの後にのみ音を許可するため、先にアラームを追加やサウンドを試すを押すことが大切です。その後、サウンドを試すを押して音が出ることを確認してからアラームを頼りにしてください。

アラームは複数設定できますか？

はい — 好きなだけ設定できます。各アラームには独自の時刻、ラベル、サウンド、オン／オフスイッチがあるため、一日分のリマインダーを保ち、削除せずにそれぞれオン・オフできます。

スマートフォンでも使えますか？

はい。このページはスマートフォン、タブレット、パソコンで動作し、大きな表示は離れていても読みやすく、全画面モードでベッドサイド風の時計になります。タブを開いたままにし、ブラウザが対応していれば「画面をスリープさせない」をオンにして表示がスリープしないようにしてください。朝のアラームには、スマートフォンを一晩充電しておくのがおすすめです。

アラームは保存されますか？

はい — このブラウザ、このデバイスに保存されます。アラームと12／24時間表示の設定はローカルストレージに保存され、ページを開き直しても残っています。他のデバイスやブラウザには同期されず、ブラウザのサイトデータを消去すると削除されます。
