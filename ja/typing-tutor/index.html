タイピング学習チューター — テストだけじゃない、本物のレッスン

要するに： このチューターはステップバイステップでタイピングを教えます：12の短いレッスンでホーム段からキーボード全体まで — 大文字と数字も含めて — 進み、画面上のキーボードが次のキーを毎回光らせます。レッスンを正確さ85%以上で終えると次のレッスンが開きます。

タイピングテストはあなたを測るだけです。決して教えてはくれません。このチューターはそのもう半分です：一度に数個のキーを紹介し、簡単だと感じるまで練習させ、あなた個人がミスするキーを記録し、準備ができたときだけ次に進む、辛抱強いコースです。短いレッスンと星のごほうびがあるやさしいキッズモードもあります。あとで速さを測りたいときは、Loona Text Tools のタイピングテストを受けてみましょう — まずはここで学んでください。

🔒 設計上プライベート：レッスンは完全にこのデバイス上で実行され、進捗はこのブラウザにのみ保存されます — 何もアップロードされたり共有されたりしません。

あなたのキー正確さ

使い方

  1. レッスンを選ぶ — レッスン1（ラテン文字キーボードのホーム段）から始めましょう。ロックされたレッスンは、前のレッスンをクリアするごとに1つずつ開きます。
  2. 光る文字を入力する — 画面上のキーボードが次に押すべきキーを正確に光らせます。指がすべてのキーの場所を覚えます。
  3. 間違ったキーでは先に進めません — 正しいキーを押して続けてください。間違いは正確さに数えられ、キー正確さパネルに記録されます。
  4. 正確さ85%以上で終える（キッズモードでは75%）と次のレッスンが解放され、レッスンの WPM と正確さが表示されます。
  5. 毎日戻ってくる — 1日10分のレッスンは、1回の長いセッションよりも速く本物のタッチタイピングを身につけます。

仕組み

このコースは、タイピング学校が使う古典的なタッチタイピングの順序に従います：まずホーム段（指のホームベース）、次に上段、次に下段、次に Shift を使った大文字、最後に数字と完全な文です。各レッスンでは新しいキーを数個だけ追加し、すでに知っているキーと混ぜます。これがまさに筋肉の記憶が形成される方法です。チューターはキーごとにすべての打鍵を記録するので、キー正確さパネルであなた個人の苦手なキー — 追加の練習が価値あるキー — を示すことができます。

よくある質問

タイピングテストとどう違うのですか？

テストは文章とスコアを与えるだけです — すでにタイピングできることが前提です。このチューターは教えます：一度に2つのキーを紹介し、練習させ、画面上のキーボードで次のキーを示し、あなた個人の苦手なキーを記録し、レッスンを順番に解放します。まずはここで学び、準備ができたと感じたら Loona Text Tools のタイピングテストで自分を測ってみましょう。

キッズモードとは何ですか？

お子様向けの、より短くやさしい道のりです：レッスンごとの文章が少ない6つのミニレッスン、大きくて親しみやすい目標、星のごほうび。お子様は85%ではなく75%の正確さで次のレッスンを解放できます。その年齢では、プレッシャーよりも励ましが大切だからです。

WPM と正確さはどのように計算されますか？

正確さは、正しい打鍵数を、間違いを含むすべての打鍵数で割ったものです。WPM は、単語あたり5文字という標準的なタイピングの慣例を使い、正しく入力された文字だけを数え、最初の打鍵から最後の打鍵までの時間で計算します。間違ったキーを押しても決して先に進みません — 本物のタッチタイピング練習とまったく同じように、正しいキーを押して続けます。

進捗は保存されますか？

はい — このデバイス上にのみ保存されます。解放したレッスン、ベストスコア、キーごとの正確さはブラウザのローカルストレージに保存され、サーバーには決して保存されず、誰とも共有されることはありません。削除するには「すべての進捗をリセット」を使ってください。
