学習ツールとは何か — そしてなぜ機能するのか？

学習ツールは、受動的な読みを能動的な学習に変える、小さく焦点を絞ったヘルパーです。学習に関する研究は、同じいくつかの技法を指し示し続けています： 想起練習 (読み返すのではなく自分をテストすること)、 間隔反復 (間隔を広げながら復習すること)、 意識的な練習 (適切な難易度の新しい問題)と 計画 (実際に目で見える時間割)。このページの各ツールは、そうしたテクニックのいずれかを中心に作られています。

フラッシュカード 古典的な想起練習のツールです：質問を見て、答えを思い出そうとし、それからカードをめくります。私たちのフラッシュカードメーカーは、シャッフルモードと 知っている／知らない の追跡を追加しますので、デッキはすぐに、あなたが習得したものと、まだ作業が必要なものに自身を分類します。

クイズ クラス全体に対して同じ仕事をします。教師は数分でクイズを構築できます — 多肢選択、真／偽、短答の問題 — 生徒にどのデバイスでも、即座の採点付きで挑戦させたり、紙のテストのためにクイズと別の解答を印刷したりできます。

ワークシート コピー機の行列なしで、意識的な練習を与えてください。演算、数の範囲、希望する問題数を選ぶと、ジェネレーターは毎回、全く新しいランダム化されたワークシート — とその解答 — を作成します。

読書速度 重要です。なぜなら、遅く努力を要する読みは、理解のための精神的エネルギーを少なく残すからです。私たちの読書速度テストは、文章全体でのあなたの真の速さを測定し、それから理解度をチェックします。なぜなら、理解なしの速さは単なる流し読みだからです。

練習ドリル 日常の基礎をカバーします：時間制限のあるラウンド付きの九九、単語を声に出して読むスペリングテスト、文字、数字、あなた独自の単語リストのための手書きシート。試験の時期には、 試験カウントダウンプランナー あなたの科目を、残りの正確な日々に広げます。教室については、教師はまた次も得られます ワードサーチジェネレーター, 一つの マッチングワークシートジェネレーター そして公平な ランダム名前ピッカー.

時間割 良い意図をプランに変えます。プランナーに、あなたの科目、一日に正直に持っている時間数、試験日を伝えてください。すると、科目を公平に回転させるバランスの取れた週間グリッドを構築します — 印刷して机の上にピン留めする前に編集可能です。

なぜ Loona Study Tools を使うのですか？

  • 設計上プライベート： あなたのフラッシュカード、クイズ、時間割は、あなたのデバイスを決して離れません。あなたの作業のサーバーコピーはありません。
  • 本物の教室のために作られました： A4 用紙できれいに見える、印刷可能なワークシート、クイズ、解答。
  • アカウントは一切ありません： ツールを開いて、数秒で作業を開始してください — 学校のコンピュータや共有デバイスに最適です。
  • あなたの作業は持ち運び可能です： フラッシュカードデッキを CSV または JSON として、クイズを JSON としてエクスポートしてください。何もロックインされません。
  • ホイールを回します： 教室 名前のホイールは Loona Calculators にあります — ネットワーク全体に対して一つのホイールであるため、ここでは複製するのではなくリンクされています。
  • Loona ファミリーの一員： これらと組み合わせてください Loona Text Tools のタイピングテスト, 時間ツールは次のページにあります： Loona Hours そして GPA 計算ツールは Loona Calculators.

よくある質問

Loona Study Tools は本当に無料ですか？

はい — このページのすべてのツールは完全に無料で、登録不要、アカウント不要、透かしなしです。それらは、目立たない広告によって支えられているため、生徒と教師は決して支払う必要がありません。

何かをインストールしたり、アカウントを作成したりする必要がありますか？

いいえ。すべてのツールは、スマートフォン、タブレット、コンピュータ上のウェブブラウザで直接動作します。ダウンロードするものも、作成するアカウントもありません。

私の作業はプライベートですか？ フラッシュカードとクイズはどこに保存されますか？

あなたのデッキ、クイズ、時間割は、あなた自身のデバイス上の、あなた自身のブラウザのローカルストレージにのみ保存されます。あなたが入力したものは、サーバーにアップロードされません。あなたの作業をファイル (CSV または JSON) としてエクスポートして、バックアップを保持したり、別のデバイスに移動したりできます。

私は教師です。ワークシート、クイズ、フラッシュカードを印刷できますか？

はい。算数ワークシートジェネレーターは、きれいなワークシートと別の解答を印刷します。クイズメーカーは、クイズと別の解答を印刷します。フラッシュカードには、カードを紙の上に配置し、切り取る準備ができる印刷モードがあります。

ここにはタイピングテストやポモドーロタイマーはありますか？

すべてのツールを一つの家に保つため、タイピングテストは Loona Text Tools にあり、タイムカードや時間計算ツールのような時間ツールは Loona Hours にあります。両方へのリンクは、すべてのページのフッターにあります。そして GPA/CGPA 計算ツールは Loona Calculators にあります。

ツールはオフラインで動作しますか？

ページが読み込まれたら、ツール自体は完全にオフラインでも機能します。なぜなら、すべてのロジックがあなたのデバイス上で実行されるからです。保存したデッキとクイズもブラウザで利用可能なままです。

このツールをウェブサイトに埋め込む — 無料

このツールをご自身のウェブサイトやブログに追加してください — 完全無料で登録も不要、常に最新バージョンが表示されます。下のコードをコピーし、ツールを表示したい場所に貼り付けてください。埋め込みの下にある小さな “Powered by Loona Automation” のクレジット表記を残していただくと、このツールを無料で提供し続ける助けになります — ただし、スタイルを変更したり削除したりしても自由です。ツールはどちらの場合も動作します。
