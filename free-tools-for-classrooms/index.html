Free Tools for Classrooms & Nonprofits

In short: this page is a free resource kit for teachers, schools, education nonprofits and resource curators. Every tool listed below is completely free to use in your classroom or programme — no sign-up, no download, no installation, and no payment. The tools run entirely in the web browser, so the names, marks and files your students and staff enter stay on their own device and are never uploaded to us.

Good classroom software is often locked behind subscriptions that small schools, community learning centres and nonprofits simply cannot pay for. Loona Study Tools was built to remove that barrier: practical tools for planning, teaching, practising and assessing — free for every classroom, everywhere. This page collects the main tools in one place, with a ready-made one-line description for each, written so that teachers, librarians, bloggers and resource curators can copy a line straight into their own resource lists, newsletters, school websites and learning platforms.

Made by a Teacher

Loona Study Tools is built by Aurang Zeb Loona, a practising school teacher and the founder of Loona Automation. The tools come from real classroom work — they are designed to be simple enough for any teacher or student to use in seconds, on any device, without training or setup.

Good to Know

  • Truly free: no accounts, no trials that expire, no locked features and no watermarks on printouts.
  • Private by design: the tools run 100% in the browser. Student names, marks, class lists and files are processed on the user's own device and are not uploaded or shared. Standard anonymous analytics, as described in the site Privacy Policy, are the only exception.
  • Works anywhere: any modern browser on a phone, tablet, Chromebook or computer — nothing to install, and pages are light enough for slow school connections.
  • The full collection: this kit lists the main tools. The complete, always-updated collection is on the Loona Study Tools home page.
